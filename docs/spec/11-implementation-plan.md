# 11. Порядок реализации

Техническое предложение к итоговому пакету. Начать с `07-stack-options.md` и принять стек в процессе запуска разработки; текущий пакет не создаёт рабочий клиент.

1. **Каркас и сохранность.** Typed domain, SQLite с единственным писателем, миграции, тестовая фикстура, транзакции, история/отмена, экспорт/проверяемое восстановление. Gate: сохранение, перезапуск и конфликт версии проходят руками и тестом.
2. **Ручной день.** Сегодня/Сейчас/Позже/общий список, доска и свои колонки, карточка/подзадачи/комментарии/вложения. Применить выбранные токены сразу. Gate: AC-01–AC-04 и AC-10; дела полезны без AI.
3. **Повторы и риск.** Экземпляры, пропуски, перенос незавершённого, оценки в исходных единицах и предварительный риск. Gate: AC-05/AC-09; не теряются пропуски, нет фиктивного точного прогноза.
4. **Правила.** JSON Schema, проверка ссылок/конфликтов, импорт/экспорт, предыдущая активная версия, привязки. Gate: AC-08 и сценарии `10-rules-format.md`.
5. **AI-адаптер.** Сначала проверить поддерживаемый способ подписочной интеграции. Контекст, чат, создание, перестройка, Auto/подтверждения, устаревшие предложения. Gate: AC-06/AC-07/AC-12; ни один скрытый фоновой запрос.
6. **Modeus.** Техническая проверка способа получения расписания, затем снимки/обновления/ошибки. Gate: AC-11; сбой не обнуляет занятость. Владелец отдельно предоставляет доступ при реальном подключении.
7. **Mac-приёмка.** Обе темы/четыре ширины, клавиатура/VoiceOver, файлы/разрешения, чистая установка, упаковка и ресурсы. Gate: `../design/e-handoff.md` и весь набор AC.

Параллельная работа допустима только после стабилизации контрактов, с явным владением файлами. Это организационная рекомендация для будущей разработки, не команда запускать агентов сейчас. Порядок не является оценкой календарных сроков.
