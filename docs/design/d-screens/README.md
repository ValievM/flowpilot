# Финальные экранные макеты

Принятый визуальный язык: `signal-serif`, revision 2. Самостоятельные HTML без сборки, обе темы через `?theme=light|dark`. `index.html` — каталог, `manifest.json` — перечень, PNG рядом.

Основные Today/Now воспроизводят одобренную композицию. Остальные поверхности — согласованные с требованиями макеты дизайнера для передачи, а не отдельное утверждение владельца каждого экрана. Меню-бар обозначен P1-концептом. Inbox здесь — общий список, а не обязательная очередь ручной сортировки.

Данные вымышлены. AI, Modeus, системные разрешения и семантическая проверка правил демонстрационные. Работают локальный ввод/редактирование/статусы/комментарии, просмотр экранов, тема и часть демонстрационных действий. Результат не является рабочим клиентом.

Формальные критерии поведения — в `../../spec/02-calendar-spec.md`; визуальные токены — в `../c-system/`. Все функциональные обещания реализации отделены от проверенных действий HTML в `../final-qa.md`.
