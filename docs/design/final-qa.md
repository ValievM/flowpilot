# Итоговая проверка пакета

04.10.2026. Проверены документы и HTML-макеты на вымышленных данных. Это не приёмка рабочего приложения.

## Выполнено

| Проверка | Результат / доказательство |
|---|---|
| Полнота требований | 15 P0, у каждого Given/When/Then; все покрыты 12 сквозными сценариями в `spec/04-acceptance-scenarios.md`. |
| Экранный комплект | 22 HTML, у каждого PNG светлой и тёмной темы: 44 основных изображения. [Манифест](d-screens/manifest.json). |
| Размеры окна | 176 сочетаний: 22 экрана × 2 темы × 900/1280/1440/1728 px. Горизонтального переполнения нет. [Результаты](d-screens/qa/width-results.json). Это подсчёт проверок, не лимит продукта. |
| Визуальная проверка | Просмотрены все основные PNG на шести сравнительных листах; дополнительно «Сегодня» в обеих темах при четырёх ширинах. Контуры, перенос текста, панели и кнопки не обрезаны. Листы `d-screens/qa/sheet-1.png`–`sheet-6.png`. |
| Загрузка | 44 состояния открылись с основной рабочей областью, без зарегистрированных ошибок JavaScript. [Результаты](d-screens/qa/capture-results.json). |

| Текстовый контраст | Проверенные основные пары: светлая 4,80–13,35:1; тёмная 6,39–15,60:1. Проверка вычисляет относительную яркость HEX по WCAG. AA для этих пар выполнен; полная сертификация доступности не заявлена. |

Функциональные проверки сделаны Playwright в Chromium. Основные снимки — 1440 px, дополнительные — в `d-screens/qa/`. Макеты сохраняют одобренный язык Signal Document; остальные экраны — дизайнерская разработка по спецификации, а не отдельное утверждение владельца каждого состояния.

## Границы проверки

- Настоящие AI, Modeus, авторизация, SQLite, восстановление после перезапуска, доставка уведомлений и сборка Mac-клиента не запускались. Приёмка этих частей — в плане реализации.
- В макете правила и ответы AI демонстрационные: работа кнопки привязки не доказывает работу JSON Schema или семантического линтера. Их проверяемый контракт задан отдельно в `spec/10-rules-format.md`.
- VoiceOver, полный обход клавиатурой, увеличение текста до 200%, системная тема, реальный Dock и подписанный выпуск требуют проверки в реализованном приложении. Дизайн-контракты есть в `c-system/a11y.md` и `macos-feel.md`.
- Типографика системная: переносы на других платформах могут отличаться. Адаптация 900 px предназначена для узкого Mac-окна; это не мобильный интерфейс.
- Старое приложение не изменялось. Его аудит относится к чтению исходников, а не запуску с реальными данными.
