# Доступность

Цель реализации: WCAG AA для применимых веб-критериев и нативная доступность macOS. Проверка токенов не заменяет полного аудита.

- Основной текст минимум 14/15, вторичный 12; 11 только для необязательных метаданных. Риск и действие читаются без цвета.
- Контраст обычного текста ≥4,5:1, крупного ≥3:1. Контур фокуса ≥3:1 относительно соседней поверхности. Контраст иконок действия проверяется отдельно от декоративных разделителей.
- Фокус видимый: 2 px акцента с отступом 3; не удалять outline без замены. Все действия доступны клавиатурой; перетаскивание имеет меню статуса/перемещения.
- Диалог удерживает фокус, Escape закрывает, закрытие возвращает инициатору. Панель деталей имеет название; Save доступна при прокрутке.
- VoiceOver: «Сегодня, выбрано», «Изменить статус задачи …», «Риск не успеть: …», «Применить три изменения». Уведомления `aria-live=polite`, ошибки формы связаны через `aria-describedby`.
- Label отличен от placeholder. Обязательное поле обозначено; оценка явно необязательная. Ошибка сохраняет введённые данные.
- При масштабе текста 200% нет потери текста/кнопок: колонки переходят в последовательное представление, горизонтальная прокрутка допустима только у календарной сетки с доступной альтернативой списком.
- Авто-тема, Reduce Motion, Reduce Transparency, повышение контраста учитываются. Анимация не несёт единственный смысл.
- Удалённые бинды доступны из меню/справки и tooltip. Tooltip не является единственным доступным названием кнопки.

Числа — нормативные критерии/дизайнерские размеры, не измерение готового приложения. Текущие замеры и ограничения находятся в `../final-qa.md`. VoiceOver и 200% масштаба должны пройти отдельную проверку реализации.
