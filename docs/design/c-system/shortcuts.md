# Клавиши без визуального мусора

Сочетания показываются в меню, tooltip и отдельной справке. Главный экран не содержит футера с биндами. Цитата владельца: «не надо крч мусорить :}».

| Действие | Сочетание / контекст |
|---|---|
| Новая задача / быстрые действия | ⌘K |
| Поиск по задачам | ⌘F; внутри ввода работает обычный поиск/редактирование текста |
| Закрыть панель | Escape; вернуться к инициатору |
| Сохранить карточку | ⌘Enter, только в открытой карточке |
| Создать задачу | Enter, когда фокус в поле быстрого ввода |
| Новая строка в сообщении | Shift+Enter; отправка Enter только если выбран этот режим ввода |
| Предыдущий/следующий день или неделя | ⌥← / ⌥→, когда фокус в навигации календаря; не перехватывать редактирование текста |
| Следующая/предыдущая задача | ↑ / ↓ в очереди; Tab — между действиями |
| Изменить статус | Через меню карточки; Space/Enter открывает меню, стрелки выбирают |
| Отмена совместимого действия | ⌘Z вне редактора; внутри поля остаётся обычная отмена текста |

Глобальные сочетания не входят в первый выпуск. Системные ⌘Q, ⌘W, ⌘, и стандартные операции с текстом сохраняются. В HTML реализованы Cmd/Ctrl+K, Escape и нативная работа контролов; остальные сочетания — контракт для реализации, а не скрытые обещания прототипа.
