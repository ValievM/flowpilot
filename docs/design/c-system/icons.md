# Иконки

Выбран синий концепт «Сигнал»: F с выходом вперёд. Он сохраняется в смешанном направлении. Иконка — единая для светлой и тёмной macOS; внутренние пиктограммы принимают цвет темы.

`icons/app-icon.svg` — векторный мастер 1024; `app-icon-1024.png` — растровый мастер; `app-mark.svg` — монохромный знак. `icons/ui/` — 15 исходных пиктограмм в сетке 24×24. Штрих 1,65, скруглённые окончания; знак приложения 2,4. По умолчанию вывод 18–20 px, без emoji вместо системных действий.

В рамках передачи SVG/PNG достаточно для любого стека. Нативный пакет готов: `icons/FlowPilot.icns` и `icons/FlowPilot.iconset/` с 10 файлами стандартных размеров/Retina, от 16 до 1024 пикселей. Экспорт выполнен из SVG; `.icns` собран системным iconutil. Нужна визуальная приёмка в реальном Dock после установки. Файлы, создаваемые из SVG, не являются альтернативными вариантами бренда.
