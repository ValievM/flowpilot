# Компоненты выбранного направления

Основа: «Сигнал» + засечки в заголовках страниц + нейтральные поверхности. Светлая версия и уточнённая тёмная приняты словами «ахуенно бро, готово». Размеры ниже — параметры дизайнера. Цвета и размеры берутся из `tokens.json`; сетка отступов 4 px.

| Компонент | Геометрия и варианты | Состояния и поведение |
|---|---|---|
| Окно и навигация | Рейка 72; кнопка 44; верхняя строка 56; рабочий отступ 24/32 | Активное представление видно по заливке и подписи для VoiceOver. Hover спокойный. Недоступный пункт скрывается, а не оставляет пустую функцию. |
| Заголовок дня | Georgia 42/36, вес 400, строка 1,15; подзаголовок 12 | Засечки только в заголовках страниц. Названия задач системные 15. Крупный текст переносится, не обрезается. |
| Очередь/Inbox | Строка около 100 при стандартном содержании, отступы 24×20; адаптивная высота | Обычная: тонкая линия. Hover: muted. Selected: muted + полоса 2 px. Focus: контур акцента. Waiting/Done отмечены текстом и исключены из доступного следующего действия. |
| Задача на доске | Содержательная карточка, отступ 12/16, радиус 6 | Без миниатюрного календарного слота. Drag: исходное место сохраняет размер; drop target обозначен. Перемещение также через меню статуса. Неизвестная оценка допустима. |
| Событие | Время, название, место; линия категории; 64 px на час в обзорной сетке | Фиксированное занятие отделено от задачи и не переносится обычной перестройкой. Перекрытия раскрывают список. Показанная сетка — макет, не готовая библиотека календаря. |
| Chip/риск | Радиус 4, отступы 4×8, подпись 11/12 | Нейтральный статус; accent — выбор; warning — неизвестность; danger — риск. Цвет всегда дополнен текстом/знаком. Chip не интерактивен без явной кнопки. |
| Кнопки | Высота минимум 36; иконка 18–20; отступы 8×12 | Primary: один основной ход. Secondary: контур. Ghost: вторичные действия. Hover мягкий; pressed затемняет поверхность; focus 2 px с отступом 3; disabled не нажимается и сохраняет читаемое объяснение рядом при необходимости. |
| Переключатель вида/темы | Контролы 36; спокойная выбранная поверхность | Выбор определяет `aria-current`/состояние. Авто-тема следует macOS; ручной выбор сохраняется в реализации. Не полагаться на один цвет. |
| Быстрый ввод | Диалог шириной до 600; одно основное поле; название достаточно | Label + пример + короткая помощь внутри диалога. Пустой ввод не сохраняется. Enter добавляет, Escape закрывает; никаких постоянных подсказок клавиш на главном экране. |
| Детали | Панель до 620; название, статус, срок, оценка, описание, пункты, комментарии, вложения | Просмотр/редактирование. Сохранить закреплено снизу. Ошибка не стирает ввод; незаполненная оценка не блокирует. Отметки пунктов не завершают родителя автоматически. |
| «Сейчас» | Одно доступное действие + ближайшее фиксированное событие | Начать/Продолжить. Если занятий нет, не выдумывать занятие; если задача заблокирована, объяснить и дать следующую. Таймер не входит в P0. |
| Индикатор времени | Тонкая акцентная линия с подписью времени в календаре | Не является AI-запуском. Системный часовой пояс учитывается в реализации; дата демонстрации фиксирована. |
| AI-диалог/предложение | Чат по запросу; переключатель Auto/подтверждения; список изменений | Pending: одна операция, без повторного запроса. Confirm: сначала diff, затем применить/отказаться. Auto: применить и дать отмену. Stale: применить отключено, явное действие пересчитать. |
| Пусто/загрузка/ошибка | Текст причины и одно полезное действие; прежний контекст сохраняется | Loading не прячет старые задачи. Ошибка источника сохраняет последний снимок с давностью. AI недоступен — ручная работа доступна. Ошибки полей привязаны к полю. |
| Меню-бар | Компактный следующий шаг, одно действие открыть/начать | Исследовательский P1, не новая обязательная функция. Без глобального чата и длинной очереди. |

Все интерактивные элементы имеют нажатие, hover, видимый клавиатурный фокус и подпись. В реализации проверять disabled, loading, пустую карточку, длинные названия и конфликт сохранения отдельно. Простые пиктограммы не заменяют названия в доступном дереве.
