# Движение

- Контролы: 140 ms; открытие панели/диалога: 180 ms; кривая `.2,.7,.3,1`. Это токены, не обещание времени ответа приложения.
- Hover меняет поверхность; никаких прыжков и увеличения карточки.
- Создание/сохранение: короткое появление строки без каскада всей очереди. Фокус остаётся на полезном действии.
- Drag-and-drop: полупрозрачный переносимый объект, стабильное место, обозначенная колонка назначения. После drop допустимо короткое смещение в назначение.
- Неделя меняется без пролистывания через промежуточные дни; направление движения допускается только как короткий переход.
- «Сейчас» сокращает видимый контекст, не устраивает анимацию всего окна.
- Cmd+K появляется без длительного масштабирования. Escape возвращает фокус инициатору.
- `prefers-reduced-motion`/macOS Reduce Motion: нулевые длительности, без transform/пружин, состояния остаются различимы.
- Loading не анимирует большие поверхности: небольшой индикатор рядом с явным запросом. Он не должен выглядеть как постоянная работа AI.

HTML-макеты намеренно сдержанны: мгновенное переключение экрана, короткие CSS-переходы контролов. Описанный перенос и переходы — контракт реализации, не заявление об уже выполненной нативной анимации.
