# Передача FlowPilot в разработку

04.10.2026. Выбранный визуальный язык: **Signal Document** — композиция «Сигнала», засечки «Ритма» в заголовках страниц, нейтральная белая тема, тёмная тема revision 2. Основание: «ахуенно бро, готово». Отдельные дополнительные экраны — разработки дизайнера в рамках задания, а не дословное одобрение каждой детали.

## Источники истины

1. `../spec/01-vision.md`, `02-calendar-spec.md`, `04-acceptance-scenarios.md`: продукт и проверяемое поведение.
2. `c-system/tokens.json` + `tokens.css`: цвета, шрифты, размеры, состояния.
3. `d-screens/manifest.json` и HTML/PNG: экранные примеры. Today/Now соответствуют выбранной композиции; вымышленные данные не копировать в рабочий продукт.
4. `decisions.md`: цитаты и история выбора. `b-directions/` — исследование, не конкурирующие источники финального дизайна.
5. `../spec/07-stack-options.md`: рекомендация по реализации; дизайн остаётся переносимым.

## Порядок компонентов

Окно/темы → навигация/кнопки/поля → очередь и статусы → карточка/комментарии/вложения → доска и перенос → фиксированные события → правила/диагностика → чат/предложения/устаревание → настройки/ошибки → уведомления. Сохранность и единый обработчик изменений создаются до AI-операций.

## Критично

- Открытие сразу даёт полезные дела, без вопросов о часах и обязательной перестройки.
- Не терять незавершённое, ожидание и пропуски. Колонки меняют состояние, а не создают копии.
- Оценки приблизительные. Риск виден до последнего дня и не обещает точного прогноза.
- Занятия фиксированы; задачи без времени не выглядят часовыми блоками. Сбой Modeus сохраняет снимок и занятость.
- AI вызывается только явно. Auto/подтверждения используют один валидатор, транзакцию и проверку версии; диалог не получает собственный путь записи в БД.
- Рабочий текст системный. Засечки — только заголовки страниц. Не возвращать постоянный футер с биндами и служебными заявлениями.
- Светлая и тёмная темы — отдельные роли поверхностей; не заменять их механической инверсией. Стандартные карточки не получают яркую синюю заливку целиком.

## Что можно упростить

Первый выпуск может использовать обычные непрозрачные поверхности, моментальные смены представлений, простой обзор недели и стандартные системные file dialogs. Меню-бар, vibrancy, глобальные сочетания и декоративное движение — P1. Не упрощать сохранность, доступность клавиатурой и видимый риск.

Сравнение снимков делать на одинаковой ОС/шрифте/размере окна с фиксированными вымышленными данными и временем. Снимок с новым дизайном принимается осмысленно, а не автоматическим обновлением эталона. При различии классифицировать геометрию, шрифт, цвет, состояние.

Набор screenshot-сценариев: Today/Now, длинное название, четыре статуса/свои колонки, день с перекрытием занятий, задача в ожидании, пропущенный повтор, риск/неизвестная оценка, пустой день, Cmd+K/ошибка поля, карточка/сохранение/ошибка файла, diff/Auto/stale, настройки темы, правило без привязки/с конфликтом, source/AI error. Не писать тесты, проверяющие само название CSS-класса.

## SwiftUI и веб

| Область | SwiftUI | Веб в Electron/Tauri/Wails |
|---|---|---|
| Токены | Сгенерировать Color/Font/Spacing из JSON. HEX fallback сверить с OKLCH. | Использовать CSS variables; фиксировать один источник темы. |
| Текст | SF для работы; Georgia для display, с динамическим размером. | Системный font stack; проверить Mac-метрики и переносы. |
| Фокус/доступность | FocusState, accessibilityLabel/Value, системные menus/sheets. | Нативные элементы или доступные primitives; aria, focus trap и return. |
| Окно/меню | Стандартная Scene/Commands; AppKit только для отсутствующих возможностей. | Оболочка создаёт системное окно/меню, preload/API закрывает прямой доступ renderer к OS. |
| Drag/drop | Transferable с типизированным payload, альтернатива меню. | dnd-сенсоры клавиатуры/мыши, та же доменная команда. |
| Уведомления/файлы | Системные API с проверкой разрешения. | API оболочки, системные dialogs; не браузерные имитации. |

Обе реализации разумны. Сложные blur/вибрации и точные пружины не обязательны. Подписочная AI-интеграция, Modeus и эксплуатационные характеристики остаются техническими проверками; HTML их не доказывает.
