# Чек-лист приёмки выпуска 1 («Ручной день»)

Для владельца: пройти руками на своём Mac и отметить «получилось / нет» у каждого шага. Источник требований: `docs/spec/04-acceptance-scenarios.md` (часть «В1»). AI, чат, правила и расписание в выпуске 1 нет: их проверять не нужно.

## Как подготовиться

1. В папке проекта выполнить `npm run seed:demo`. Скрипт соберёт приложение, создаст временный демо-профиль с вымышленными данными (ничего не пишет в настоящие данные приложения) и напечатает команду запуска. Повторный запуск создаёт новый чистый профиль.
2. Скопировать напечатанную команду (она начинается с `FLOWPILOT_TEST=1 FLOWPILOT_TEST_PROFILE=…`) и выполнить её: откроется приложение. В демо-профиле «сегодня» равно понедельнику 5 октября 2026.
3. Для сценариев «с нуля» (AC-13) запустить приложение обычной командой `npm start`: у него настоящий пустой профиль.

Что в демо-профиле: 9 задач (срок и оценка по таблице AC-09, вчерашняя незавершённая с отмеченной подзадачей, ожидание с причиной, будущая, без дня, готовая) и две серии: «Тренировка» (пн, ср, пт, 18:00, три пропуска) и «Чтение 20 минут».

## Что автоматически не проверено

- **VoiceOver** на ключевых экранах: только руками.
- **Ширины 1440 и 1728 на реальном экране**: автоматические снимки есть на 900 и 1280; снимки на 1440 и 1728 и проверка прокрутки — задача #64.
- **Масштаб текста 200%**: автоматически проверена только страница «Сегодня».
- **Чистая установка упакованного приложения** (`npm run make`): смоук упакованной сборки — задача #65; подпись и нотаризация не делаются.
- **Вложения в демо-профиле**: из окна приложения файл добавляется только через системный диалог, поэтому скрипт демо-данных вложений не создаёт; проверять вручную (AC-02).
- **Часовой пояс**: демо-профиль использует фиксированное «сейчас» (понедельник 5 октября 2026, 12:00 UTC); в поясах далеко от UTC дата и время «Тренировки» (18:00) относительно «сейчас» могут сдвинуться; при расхождении с ожиданием сначала сверить пояс.
