# Чек-лист приёмки выпуска 2 («Помощник и расписание»)

Для владельца: пройти руками и отметить «получилось / нет» у каждого шага. Источник требований: `docs/spec/04-acceptance-scenarios.md` (часть «В2»). Выпуск 1 принимается отдельно по `release-1-checklist.md`.

## Что сейчас подключено (честно)

- **AI:** ручной обмен (в обычном запуске) и фейковый провайдер (только в демо). Реальный Codex не подключён: проба P-1 (#15) ждёт вас. В ручном обмене приложение показывает запрос, вы копируете его в любую модель, вставляете JSON-ответ назад. Ждёт до 10 минут.
- **Расписание:** импорт файла `.ics` и ручные занятия. Подключения к Modeus нет: проба P-2 (#16) ждёт вас.
- **Уведомления macOS (AC-11):** сделаны (проверка раз в минуту, пока приложение запущено). В демо-режиме уведомления только записываются, настоящее системное окно видно в обычном `npm start`.

## Как подготовиться

1. `npm run seed:demo`. Скрипт соберёт приложение, создаст временный демо-профиль с вымышленными данными (настоящие данные не трогает) и напечатает команду запуска.
2. Выполнить напечатанную команду (она начинается с `FLOWPILOT_TEST=1 …`): откроется приложение. «Сегодня» в демо — понедельник 5 октября 2026, 12:00 UTC.
3. Чтобы увидеть ручной обмен, запустить обычное `npm start` (пустой настоящий профиль): там нет фейкового AI.

В демо-профиле, кроме данных выпуска 1: типы «Курсовая» и «Лабораторная», дисциплины «Проектирование» и «Физика» (привязаны к двум задачам), правило «Учебные проекты» (активно, привязано к «Курсовая»), «Личные проекты» (черновик без привязки), расписание из вымышленного `.ics` (Математика и Проектирование сегодня, Математика в среду). **Фейковый AI отвечает один раз** (на «Что делать сейчас?»), дальше сообщает, что недоступен: для остальных сценариев AI используйте ручной обмен.

## Что автоматически не проверено

- **Реальный Codex и Modeus**: не подключены, проверять нечем (пробы #15, #16).
- **Настоящее уведомление macOS (AC-11):** только руками (шаги выше); автоматически проверены журнал, повтор после перезапуска и запрос разрешения только по кнопке.
- **Ошибка источника расписания**: баннер «не обновлён» и давность проверены юнит-тестами интерфейса; из окна приложения ошибку источника вызвать нельзя, в e2e её нет.
- **VoiceOver**, масштаб 200% на новых экранах, упакованная сборка с новыми экранами: только руками.
- **Фейковый AI в демо** отвечает один раз; остальные ответы AI в e2e заданы сценариями, а в этом профиле их нет.
