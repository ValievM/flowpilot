# Шпаргалка: главные правила (читай первой)

Одна страница. Подробности по ссылкам; при расхождении побеждают подробные документы. Решения по процессу: Claude.

**Работа**
1. Задача = issue; читай целиком с комментариями (решения Claude в комментариях главнее текста issue). Ветка `<тип>/<N>-<слово>` от `dev`, свой worktree, основная папка только для чтения (`AGENTS.md`).
2. Смотри метку уровня: `tier:a` (данные, контракты, безопасность: полная церемония), `tier:b` (экраны и логика без риска данных), `tier:c` (CI, документы, конфиги). Нет метки = как tier:a (`pipeline.md`).
3. TDD: красный тест до кода и красный по смыслу (не «нет такой функции»). Мутации: tier:a для каждого нового теста с логикой, tier:b одна на файл, tier:c не нужны (`AGENTS.md`).
4. Перед сдачей полный `npm run check` (и `npm run e2e` для интерфейса) через `~/.agent-runner/run <роль>`, логи с `exit=0` **для сдаваемого коммита**, `git status` чистый.
5. Перед сдачей самопроверка по чек-листу ревьюера и строка в отчёте (`reviewer.md`).
6. Сомнение или противоречие: вопрос Claude комментарием (`[GPT-N] ВОПРОС`), метки `who:claude` + `status:blocked`. Не выбирай молча, не спрашивай владельца.

**Код** (`code-style.md`)
7. Файл до 300 строк, функция до 50 (компонент до 150), до 4 параметров, сложность до 10, вложенность до 3, один класс на файл. Никаких `utils/helpers/manager/common`, циклов импортов, «божественных» объектов.
8. Ошибки значением (`Result`), не исключением; состояния дискриминируемыми объединениями; без `any`, неоправданных `as`; данные неизменяемы.
9. Время, id, случайность приходят аргументами; в `domain` нет `Date`, Electron, React, Node, SQLite.
10. Новая зависимость, слой, паттерн, отступление от ADR, новое разрешение macOS: сначала вопрос.

**Слои и данные** (`docs/adr/0001-stack.md`)
11. `domain` ← `storage` (единственный писатель) ← `main` ↔ `preload` ↔ `renderer`; контракты в `shared` (Zod `.strict()`). Границы проверяет dependency-cruiser.
12. Запись в БД только через `Repository.apply` (транзакция, `revision`, история); миграции новыми файлами, старые не правятся.
13. Из renderer приходят только узкие команды: никаких путей, произвольных настроек, вложений; пути выбирает main через диалоги.
14. AI только по явному запросу и только типизированными командами; вывод AI, файлы и вложения недоверенные.

**Интерфейс**
15. Только токены (`tokens.css`), тексты русские, сверка с `docs/design/d-screens/` в обеих темах; кнопки-иконки с подписью, клавиатура, фокус.
16. Снимки: окно и масштаб фиксированы, `innerWidth` проверяется, эталоны разных ширин различаются (md5); эталон обновлять осознанно, не ради зелёного.

**Тесты**
17. Проверяй поведение, не внутренности; имя теста описывает поведение; граничные и ошибочные случаи обязательны; без реального времени, сети, случайности; ничего не ослаблять, не удалять, не `.skip`.

**Сдача и проверка** (`pipeline.md`, `review.md`)
18. Цепочка по уровню: tier:a автор → коллега → ревьюер → Claude; tier:b автор → ревьюер → Claude; tier:c автор → ревьюер → автослияние. Метки точные: `who:gpt1|gpt2|gpt3|reviewer|claude`, `status:*`; после смены меток проверь результат (`gh issue view N --json labels`).
19. Замечание ревьюера или Claude правь ровно по списку, подтяни `dev`, перегони проверки, сдай заново.
20. Секретов и личных данных нигде нет (код, логи, тесты, issues); реальные AI и Modeus не запускать; пароли не вводить и не просить.
