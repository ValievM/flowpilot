# ADR 0001: стек и архитектура приложения

Статус: принято Claude 2026-10-05 по поручению владельца настроить окружение («думаю ты и без моих неграмотных заявлений понимаешь чо делать крч, настроить окружение»). Это **решение Claude**, а не отдельный выбор владельца. Основа: `docs/spec/07-stack-options.md` (рекомендация пакета).

## Решение

- **Оболочка:** Electron (Electron Forge, Vite-плагин), macOS arm64.
- **Язык:** TypeScript, режим `strict` везде.
- **Интерфейс:** React 19, CSS с токенами из `docs/design/c-system/tokens.css`, Radix Primitives для доступных диалогов и меню, dnd-kit для доски.
- **Данные:** SQLite через better-sqlite3 в main-процессе, SQL-миграции, единственный писатель, история изменений.
- **Время:** Temporal (полифилл): дата дня, точное время и часовой пояс раздельно.
- **Валидация:** Zod на всех внешних границах (IPC, ответы AI), Ajv для JSON Schema правил.
- **Качество:** Vitest (домен, хранилище на реальной временной SQLite), React Testing Library, Playwright для Electron (сценарии приёмки и снимки обеих тем), ESLint (typescript-eslint strict), Prettier, stylelint, dependency-cruiser (границы слоёв).
- **Пакеты:** npm с `package-lock.json`. Версии фиксируются lock-файлом при создании каркаса.

## Слои

`domain` (чистая логика) ← `storage` (SQLite) ← `main` (окна, IPC) ↔ `preload` (мост) ↔ `renderer` (React). `shared` хранит контракты IPC. Домен не знает про Electron, React, Node и SQLite: это позволяет позже переиспользовать его в мобильном клиенте.

## Почему так

Один язык от данных до экрана и быстрые проверки (typecheck, unit, browser) лучше всего подходят агентной разработке; принятый HTML-дизайн переносится почти без потерь. SwiftUI даёт самый нативный вид, но второй язык, долгую сборку и ручной перенос макетов. Tauri легче по памяти, но добавляет Rust и вторую границу проверок.

## Условия пересмотра

Пересмотреть в пользу Tauri, если после этапа 2 приложение в покое занимает больше ~400 МБ памяти или запуск дольше 2 секунд на Apple Silicon [гипотеза порогов, проверить замером]. Пересмотреть в пользу SwiftUI, если владелец решит, что важнее полностью нативный вид, или начнётся клиент для iPhone.

## Последствия

- Старый код на Go не переносится; из него берём только идеи и тестовые случаи (`docs/spec/07-stack-options.md`, «Перенести / переписать / убрать»).
- Подписание и нотаризация при выпуске с реквизитами владельца.
- Интеграции Codex и Modeus идут после ручного дня и только после проб с критерием «успех/провал».
